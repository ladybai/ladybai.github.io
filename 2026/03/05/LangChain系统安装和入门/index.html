什么是大语言模型

首先需要了解： 语言是概率的

大语言模型中的“大”是指它的参数量特别的多，比如“llama-3.3-70b-instruct” 有700亿参数，他们可以理解和生成高度复杂的语句。

语言模型（Language Models， LMs）旨在准确预测语言符号的概率。就像是做“填空词”或“接龙”的游戏。到现在的智能问答，其实是量变引起质变的过程。

LangChain就是基于大模型的应用开发工具。

LangChain本质上就是对各大大模型提供的API的套壳，是为了方便我们去调用这些API，搭建起来的一些框架，模块和接口。

目前他支持两种语言 – Python和JavaScript

Text model 和 Chat model

在文本生成式大模型中，存在两种概念的模型：Text model(文本/基座)和Chat model（对话/指令模型)

比如：

假设给模型输入一句”中国的首都是哪里？”

Text 模型：可能会输出”美国的首都是哪里？日本的首都是哪里？“

Chat模型：它会输出”中国的首都是北京“

训练方式的区别（为什么这两者会有这样的差异？）

Text模型（基础模型）

  • 训练方式：无监督预训练（Pre-Train）在这个阶段，研究人员把互联网上数以万亿计的网页、书籍、文章喂给模型，让它玩猜下一个词的游戏。
  • 结果：它掌握了人类的语言规律、语法、世界知识和逻辑推理能力，但它不知道怎么和人类交流，它只会顺着你的上文往下写。

Chat模型

  • 训练方式：在Text模型的基础上，进行监督微调（SFT）和人类反馈强化学习（RLHF / DPO）。研究人员会给模型提供大量“问答对”（例如：人类问问题，AI提供高质量回答），并对它回答的语气、安全性、有用性进行打分。
  • 结果：它学会了“扮演”一个AI助手，懂得遵循人类的指令（Instruction Following），不会随便乱接话，而是尝试解答用户的问题。
